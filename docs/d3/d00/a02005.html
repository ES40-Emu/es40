Detailed Description

LSI Logic 53C1020 Fusion-MPT SCSI disk controller.

The 53C1020 is a single-channel Ultra320 controller using Fusion-MPT doorbells and message queues. Its optional 512 KiB flash may contain an x86 option ROM and IOC firmware; neither image is required by the emulated IOC.

This is not a native Alpha boot device: SRM has no Fusion-MPT driver and cannot boot from it. AlphaBIOS option-ROM discovery is verified, but booting an operating system through SCSIBIOS is not. A guest operating system may use the controller through its own Fusion-MPT driver.
