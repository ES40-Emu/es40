Detailed Description

PCHIP state data.

More details in: HRM, 1.2.3.

The ES40 contains two 21272-P1 Pchips (peripheral interface chips). Each Pchip controls one 64-bit PCI bus, and interfaces it to the Cchip and the Dchips.

On PIO transfers from the CPU's (or PTP transfers from the other PCI bus), the Pchip acts as bus master on the PCI bus.

On DMA or PTP transfers from a PCI device, the Pchip acts as target on the PCI bus. To determine on which addresses to respond, each Pchip contains 4 DMA/PTP windows, that support both direct mapped and scatter-gather DMA/PTP memory access.
