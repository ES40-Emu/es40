Detailed Description

Abstract interface separating the emulated DEC 21143 NIC from the host networking method used to get packets on and off the wire.

Implementations:

  • CNetworkPcap : libpcap / npcap (Windows, and any Unix with libpcap).
  • CNetworkTap : TAP device (Linux, FreeBSD, NetBSD).
  • CNetworkSlirp : Userspace NAT ("slirp") implemented in Rust; no host privileges or pre-created interface required.
