◆ on_main_thread()

template<typename F>
void on_main_thread ( F fn)
static

Run fn on the thread that called main().

SDL wants the video subsystem, the window and the event pump all touched from that one thread. The emulator drives the GUI from the VGA card's thread instead, so every SDL call made from there is bounced across with SDL_RunOnMainThread(). Exceptions (FAILURE_*) must not escape into SDL's C event loop, so they are caught and rethrown on the calling thread. The inline path only covers calls made before main() takes ownership and calls that already run on the main thread (e.g. from within a bounced callback).
