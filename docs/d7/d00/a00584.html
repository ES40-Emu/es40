Detailed Description

Userspace (slirp) network backend.

This backend needs no host privileges and no pre-created interface: the emulated NIC is placed on a private virtual LAN whose gateway is a user-space NAT implemented in Rust (see src/network/slirp-rs). The guest gets its address over DHCP from the backend, and its TCP/UDP/ICMP traffic is translated to ordinary host sockets on the process's behalf.

The heavy lifting lives in a Rust static library linked into es40; this class is only the thin C++ side of the C ABI exposed by that library.
