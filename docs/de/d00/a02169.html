Detailed Description

DCHIP state data.

More details in: HRM, 1.2.2.

The ES40 contains eight 21274-D1 Dchips (data slice chips). Each Dchip is responsible for handling 8 bits of the 64-bit data bus (in the ES40, other configurations using less Dchips are possible). Each Dchip interfaces with the Cchip for control, with each of the Pchips, with each of the CPU's and with each of the DRAM arrays.
