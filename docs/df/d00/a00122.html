◆ tui_form()

bool tui_form ( const char * title,
FormEntry_t entry[],
vector< EditorField > & fields )

Display a form of 'num_entries' form 'entry's in a centered window with a 'title'.

Fill in the fields from 'preset'.

React to keys pressed: <UP> / <DOWN>, <ENTER>: go to previous/next field, wrapping around <TAB>, <RIGHT> / Shift-<TAB>, <LEFT>: in enum fields, go to next/previous choice <F1>: Display field description <F2>: exit form <F3>: quit form any other printable character is entered in the current field

When the form is exited, call 'check_callback' (if not NULL). If this returns FALSE, stay in the form.

The entered values are returned in a 'num_entries' wide array. The calling routine is responsible for freeing values' storage, except when leaving via <F3>. In that case, NULL is returned

Display a menu of 'num_entries' menu 'entry's in a window with upper left corner at row 'begin_y', column 'begin_x'.

React to keys pressed: <UP>, <DOWN>: go to previous/next item, wrapping around <ENTER>: if item callback is NULL: exit menu, else call its callback <F1>: Display item description <F2>: exit menu <F3>: quit menu

Returns the index of the last item selected, or -1, -2 if leaving via <F2> and <F3>, respectively.
